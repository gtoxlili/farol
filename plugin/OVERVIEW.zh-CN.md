Farol 把一块 ESP-Mosaico 开发板变成 Paseo agent 的状态屏和控制器。屏幕上的状态灯告诉你谁在干活、谁在等你，或者哪一轮出了错。在卡片上可以回答问题、权限请求和计划，也可以停止正在跑的一轮。用语音或键盘还能开新会话。这个插件向板子发送 agent 状态，并执行你在板子上的操作。

## 连接板子

装好插件后，在板子上连接。“扫描二维码”读 设置 › 这台 Host › 配对设备 里的配对码，走 Paseo 的加密中继。“直接连接”要填 Host、端口、是否用 SSL 和 daemon 密码。需要 Paseo 0.14 或更新。

## 设置

- 从板子开始新会话：会话用的 workspace 和 agent 配置。两个都选了，板子才能开会话。语音转文字用的是 Paseo 自己的语音输入设置。
- 允许板子操作 agent。关掉后所有板子只读。
- 板子的语言，可以跟随 Paseo，也可以固定成中文或英文。
- 完成卡的回复预览，以及是否包含后台 workspace 里的 agent。
- 所有板子共用的声音、LED 亮度和安静时段。板子自己控制中心里的改动只影响那一块板子。
- 板子时钟用的时区，留空跟随这台电脑。

## 需要知道的

- 板子里存着 daemon 密码，走中继时还存着配对码，二者都能完全控制这台 daemon。板子丢了就改 daemon 密码。
- 板子上的停止会在这台电脑上运行 `paseo stop`，只停板子当时显示的那一轮。daemon 的 PATH 里没有 `paseo` 命令行时，板子不能停止一轮。
- 板子上的回答只有被 Paseo 采用才算数。你先在别处回答了，板子会告诉你。
- 板子上的回答和停止会在 agent 的时间线里留一行，只给你看，模型看不到。
- 板子用 20 秒的请求等消息，daemon 日志会把每一次记成慢请求，这是正常的。
