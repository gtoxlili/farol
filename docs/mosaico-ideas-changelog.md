# 1.0.0

首次发布。

- 灯光汇总所有 Paseo agent 的状态：干活时冷色呼吸，等你时琥珀色，失败时红色；光的高低跟着最紧的用量额度。
- 每个 agent 一张卡片：在板子上回答问题、权限请求和计划，按住停止正在跑的一轮，完成的卡片可标为已读。
- 按住 AI 键用语音开新会话，由 Paseo 的语音输入转成文字；也可以用键盘输入。
- 两种连接方式：扫 Paseo 的配对码走加密中继，或直接填 Host、端口、SSL 和密码。用摄像头模块扫码连 Wi-Fi。
- 额度页、控制中心（Wi-Fi、Paseo、勿扰、声音、振动、亮度），扣放勿扰；可选交互模块提供接近唤醒、环境光调光和 LED 状态灯。
- 板子与插件支持中文和英文，跟随 Paseo App 的语言。
